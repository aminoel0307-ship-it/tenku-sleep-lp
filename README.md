# 天空睡眠®︎ドライヘッドスパスクール — ランディングページ

「天空睡眠®︎ドライヘッドスパスクール」の無料説明会申込みを獲得するための、日本語1ページ完結型LPです。
ビルドツールを使わない、静的HTML/CSS/JSのシンプルな構成です（`amy-1p` と同じ構成・デザイントーンを踏襲しています）。

## 構成

```
index.html      … LP本体（全13セクション、SEO/OGPメタタグ込み）
css/style.css   … スタイル（黒×ゴールド×アイボリー、モバイルファースト）
js/config.js    … CTAリンク先（公式LINE友だち追加URL）の設定（ここを書き換えるだけでOK）
js/script.js    … CTAリンクの反映など最小限のJS
favicon.svg     … ファビコン
README.md       … このファイル
```

## ローカルでの表示確認

ビルド不要です。任意の簡易サーバーで配信して確認してください。

```bash
cd tenku-sleep-lp
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。

## 申込みリンク（公式LINE）の変更方法

`js/config.js` の `seminarUrl` の値を、実際の公式LINE友だち追加URLに書き換えるだけで、
ページ内すべての「無料説明会に申し込む」ボタンのリンク先が一括で更新されます。

```js
window.SITE_CONFIG = {
  seminarUrl: "https://lin.ee/xxxxxxxxx" // ここを実際のURLに変更
};
```

## 公開前に必ず差し替えていただきたい項目

このLPは雛形として、内容が未確定の箇所を `◯◯` 等のプレースホルダーで示しています。
公開前に、以下の項目を実際の内容に差し替えてください。

- **`js/config.js` の `seminarUrl`**（公式LINEの友だち追加URLの実URL）
- **監修医師の情報**（「なぜ、医療監修なのか」セクション）
  - `index.html` 内 `◯◯ ◯◯ 医師` `◯◯病院 ◯◯科` の部分
  - 医師の氏名・所属・専門分野・監修コメントを正式にご提供いただき次第反映してください
- **主宰者プロフィール**（「主宰者紹介」セクション）
  - `index.html` 内 `◯◯ ◯◯` および経歴文を、実際の内容に差し替えてください
- **無料説明会の開催形式・日程**（現在は「オンライン個別開催・随時受付中」という汎用表記にしています。固定の開催日程がある場合は、日時を明記する形に変更してください）
- `index.html` 内 `<link rel="canonical">` と OGP用URL（`og:url` / `og:image` / `twitter:image`）の `https://example.com/` を本番ドメインに変更
- **OGP画像（`og-image.png`）**：現時点では未作成です。SNSシェア時のサムネイル用に、1200×630pxのブランド画像をご用意のうえ、リポジトリ直下に `og-image.png` として追加してください
- フッターの「プライバシーポリシー」「特定商取引法に基づく表記」「お問い合わせ」リンク（現在は仮のリンク `#` です）
- カリキュラム内容・受講料・資格認定の条件など、正式な情報が確定次第、各セクションの内容を見直してください

## デザイン意図

- ベースカラー：黒（`#0a0a0a`）／アクセント：ゴールド・アイボリー・ホワイト（`amy-1p` と統一）
- 見出しに明朝体（Shippori Mincho）、本文にNoto Sans JPを使用し、上質・専門性のある印象に
- 「医師監修」という信頼要素を、監修医師カードとして独立したセクションで明示
- 写真素材に頼らず、余白とタイポグラフィ、細いゴールドラインで高級感を表現（写真をご用意いただければ、ヒーローや講師紹介セクションに追加可能です）
- スマートフォン表示を基準に設計し、768px以上でレイアウトを拡張
- FAQは `<details>/<summary>` を使用し、JS不要でアクセシブルに実装
